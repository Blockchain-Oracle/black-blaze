# Hackathon Overview

**Official title:** Backblaze Generative Media Hackathon: Build with Genblaze on B2  
**Format:** Online and public  
**Organizer/Sponsor:** Backblaze, Inc.  
**Technology sponsor:** GMI Cloud  
**Devpost challenge ID:** 30205  
**Official page:** https://backblaze-generative-media.devpost.com/

## Official objective

Create a useful, creative, production-minded app for AI-generated video, image, audio, or multimodal workflows. Generated assets should move through an actual pipeline and land durably in Backblaze B2.

## Required products

### Backblaze B2

S3-compatible object storage. Official examples of what to store include:

- generated images, video, and audio;
- metadata and provenance manifests;
- thumbnails and previews;
- logs and application assets;
- durable intermediate and final outputs.

The first 10 GB of storage is free according to the current official pricing page.

### Genblaze

An open-source Python SDK for generative-media pipelines. It unifies media providers, supports chaining and concurrency, handles retries/fallbacks, persists assets, and creates canonical SHA-256 provenance manifests.

### GMI Cloud

Optional model provider. The event offered credits to the first 270 eligible signups. Manager replies in the discussion forum indicate this allocation was exhausted and direct later participants to the multi-provider sample. A GMI account is not a core rule requirement.

## Official example categories

- AI video generation or editing
- Image generation/remix/transformation
- Audio, music, or voice workflows
- Multimodal applications
- AI media libraries and search/tagging
- Provenance-aware archives
- Agentic pipelines that generate, evaluate, retry, and store
- Creator, marketing, education, entertainment, and developer tools
- Model-comparison tools
- Workflows producing media plus metadata, thumbnails, and final assets

Examples are inspiration, not bonus categories.
