# Legal, IP, Privacy, and Safety Checklist

## Ownership

- [ ] Team owns every original code, design, text, and media component.
- [ ] All contributors and contractors have assigned necessary rights.
- [ ] Open-source dependencies have compatible licenses and notices.
- [ ] No participant repository code, brand, assets, or copy was reused without permission.

## Models and providers

- [ ] Provider terms allow the input content and intended output use.
- [ ] Model and provider names are accurately disclosed.
- [ ] No fake claim of a live provider call when a mock/fallback generated the output.
- [ ] Content-policy refusals and degraded/fallback behavior are represented honestly.

## Demo and submission media

- [ ] Video is under 3 minutes and publicly visible.
- [ ] Music is original, licensed, generated under usable terms, or absent.
- [ ] No unlicensed third-party trademarks or footage.
- [ ] User data, API keys, bucket credentials, private URLs, and personal identifiers are redacted.
- [ ] Every claim in the narration is demonstrable.

## Privacy and security

- [ ] Uploads are validated for type and size.
- [ ] User-provided URLs are protected against SSRF.
- [ ] Secrets stay server-side and out of logs/manifests.
- [ ] B2 keys are least-privileged and bucket-scoped.
- [ ] Private assets use secure access; public assets contain no sensitive data.
- [ ] Prompts and provenance metadata do not expose confidential information.
- [ ] Test accounts contain only synthetic/non-sensitive data.

## Prize readiness

- [ ] Legal name/address and identity documents can be supplied if selected.
- [ ] Team representative and internal prize split are agreed in writing.
- [ ] Non-US tax form readiness (potentially W-8BEN) is understood.
- [ ] Nigerian bank can receive the likely payment route, but no unsupported guarantee is stated.
